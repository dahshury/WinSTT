# WinSTT 0.1.3-beta.1 — First beta

Released October 12, 2026. This is WinSTT's first beta, bringing together the changes since v0.1.3-alpha.11. It remains a prerelease; please report regressions with your OS, engine, model and reproduction steps.

## More resilient local transcription

- Local speech recognition and word alignment now run in supervised child processes. A native inference or GPU driver crash is contained in the worker instead of terminating the desktop app.
- Inference requests have deadlines. Cancellation can terminate a stuck worker without waiting for its engine lock, and failed GPU worker transport can retry once in a fresh CPU worker.
- Streaming recovery retains the audio and finalization sequence, including a disk-backed replay buffer for longer recordings. Live partial transcripts and the normal final-delivery flow are preserved.
- The dictation audio callback uses a bounded, preallocated ring buffer. Audio processing stays off the callback thread, and capture overflow or stream failure is reported instead of silently losing samples.
- Managed STT downloads resolve pinned repository revisions and validate expected file sizes and SHA-256 hashes. Model cache lookup prefers complete pinned snapshots and retains compatibility with legacy caches.

## More dependable microphones and Listen mode

- Dictation and Listen mode now share the same microphone selection policy, including the OS default, explicit device choices, saved priority order and clamshell microphone settings.
- Device changes refresh capture from the backend even when no renderer window is open. An ongoing dictation finishes before a pending microphone change is applied.
- Capture avoids reopening an unchanged input device. Listen mode can replace its microphone stream while retaining the existing mixer channel.
- Microphone pickers and level previews follow the actual system default more consistently, and feedback handles priority-selected and unavailable devices correctly.

## Import and export vocabulary

- Dictionary and snippet settings now offer import and export controls. Exports use versioned WinSTT JSON files with native save dialogs.
- Import WinSTT JSON, CSV and dictionary word lists. VoiceInk dictionary exports are supported, including replacement rules.
- Imports validate the complete file before updating settings, preserve existing entries, deduplicate case-insensitively and report added or skipped entries. Malformed or oversized files leave the collection unchanged.
- Transfer controls are translated across all 20 supported locales.

## Faster startup and smoother model selection

- Startup work is scheduled to make the main window available sooner, with Settings and model-picker windows prepared in advance.
- Quit handling no longer waits for background initialization to finish.
- Detached model-picker placement and size tracking have been improved, with fewer redundant updates.
- Model selector tooltips and specification hover cards pause while a picker is open and resume after it closes, reducing overlapping popovers in Settings and the status bar.
- Settings adds a back-to-top control for scrolled pages, respecting reduced-motion preferences and resetting scroll position when switching tabs.

## Safer paste and cloud requests

- Windows and macOS clipboard paste restoration now checks the paste result, clipboard ownership and a quiet period before restoring prior contents. An unconfirmed paste keeps the transcript available instead of risking its loss.
- Shared cloud API requests reject redirects, preventing private audio, text or credentials from being replayed to a redirected endpoint. Custom providers must be configured with their final endpoint URL; model downloads retain their separate redirect behavior.

## Maintenance and release tooling

- Updated third-party notices and model documentation, and corrected the product comparison to distinguish verified capabilities from unmeasured speed claims.
- Added a repeatable reference-repository inventory and update script for researching other dictation apps without discarding local reference changes.
- The release pipeline now supports numbered alpha and beta versions and includes these curated notes alongside the commit history. All shipped OS packages continue to pass through their build and package-audit jobs before publication.

## Scope and beta feedback

- Worker isolation covers STT and word alignment. TTS, VAD, wake-word detection and other native components retain their existing execution paths.
- S1-mini was already integrated as an English-only local cleanup option through Ollama, with its specialized prompt and streaming behavior; this release does not add it a second time or change the default cleanup model.
- Windows, Linux x64 and macOS Apple Silicon packages are produced by the release workflow. Passing CI does not substitute for hands-on microphone, GPU and clipboard testing on every OS.
- Clipboard behavior, device changes during recording, GPU failure recovery and long streaming sessions are especially useful areas for beta feedback.
