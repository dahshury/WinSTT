# WinSTT's first beta

## More reliable dictation

- Local speech recognition and word alignment run in separate, supervised processes, keeping native inference crashes from closing WinSTT.
- Stuck inference can be cancelled, and GPU worker failures can recover through a fresh CPU worker while retaining streaming audio.
- Audio capture reports overflow and stream errors instead of silently dropping samples.
- Model downloads use pinned revisions and validate file sizes and checksums.

## Microphones that follow your choices

- Dictation and Listen mode use the same microphone priorities, system default and clamshell settings.
- Device changes apply even with Settings closed. A change during dictation waits until the recording finishes.
- Microphone level previews and switch feedback follow the selected device more consistently.

## Bring your vocabulary

- Import and export dictionary words, replacement rules and snippets from their Settings pages.
- Import JSON, CSV, dictionary word lists and VoiceInk dictionaries. Existing entries are preserved, duplicates are skipped, and invalid files leave your settings unchanged.

## Smoother startup and editing

- Faster startup, responsive quit handling and prepared Settings and model-picker windows.
- Fewer overlapping tooltips while choosing models, with improved detached picker placement.
- A back-to-top control in Settings, with reduced-motion support.
- More careful clipboard restoration on Windows and macOS, keeping an unconfirmed transcript available.
- Cloud API redirects are rejected to protect private request contents. Use the final URL when configuring a custom provider.

This is a beta release. Please report any regressions with your OS, model and steps to reproduce them.
