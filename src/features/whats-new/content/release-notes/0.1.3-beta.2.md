# Promptable ASR and speaker-aware file transcription

## An optional instruction-following speech model

- Added Nemotron 3.5 Transcribe 30B-A4B alongside the lightweight streaming Nemotron models.
- Give it direct ASR instructions or reuse your Processing cleanup presets. Native cleanup skips the separate text model by default; enabling both requires confirmation.
- Edit cleanup presets without setting up a text model. Application profiles can supply presets for native ASR.
- Granite Speech 4.1 Plus accepts task prompts without being treated as a general cleanup model. Whisper hints remain context-only.

## Preserve live preview

- Final-only transcription can use a separate lightweight streaming worker for live preview.
- The preview keeps its own precision and decoder state. Changing it does not reload the large main model.
- Native child processes are terminated when their supervised worker crashes, is cancelled, or exits.

## File transcription with speaker identification

- In Output → File Transcription, enable **Identify speakers** for Nemotron Transcribe files.
- Enable **Speaker prefixes** for `Speaker 1:` labels in TXT, SRT, and copied text. JSON/CSV retain speaker IDs, JSON words carry speaker metadata, and VTT uses voice tags.
- Files follow explicit ASR prompts while bypassing the separate dictation cleanup model and dictation formatting.
- Speaker timing preserves the source timeline and overlapping speech. Missing alignment is reported rather than guessed. Nemotron files are processed as one recording, up to one hour.

## Maintenance

- Updated archive/updater, TLS, async-runtime, and Windows clipboard dependencies for the current dependency audit.
- Fixed test-order-dependent history-client coverage in Linux CI.

The optional CPU IQ4 model downloads about 21.35 GB. It was tested on an i9-12900KF with 64 GB RAM and an RTX 3080 Ti; peak resident memory was about 35 GiB, so 64 GB RAM is recommended. It uses a verified NVIDIA nightly runtime and pinned community GGUF weights. Keep the lightweight model for responsive live transcription. File diarization is offline, not live diarization.
