# What’s new in WinSTT

## Smarter setup and model selection

- Suggested models make it easier to choose a good local STT model for your hardware.
- Shared pickers now keep local STT, cloud STT, TTS, Ollama, onboarding, and settings behavior consistent.

## More control over every app

- Per-app profiles can tailor LLM processing to the foreground application.
- Transcription history is searchable, and transcripts can be exported in additional formats.

## Faster, safer desktop builds

- Startup work is deferred more carefully, downloads are more efficient, and release packages are audited on Windows, Linux, and macOS.
- Native communication now uses typed generated bindings throughout the renderer.
